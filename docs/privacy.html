隐私政策

最后更新：2026年4月5日

📋 引言

欢迎使用龙虾AI排行榜（以下简称"本应用"或"我们"）。本应用由 LobsterAI 开发并运营。 我们深知个人信息对您的重要性，并会全力保护您的隐私安全。请您在使用我们的产品和服务前，仔细阅读并了解本隐私政策。

🛡️ 核心承诺：本应用不收集、不存储、不传输任何用户个人信息。我们致力于为您提供安全、透明的使用体验。

📦 信息收集与使用

本应用是一款 AI 大模型排行榜展示工具，主要功能为展示来自公开数据源的 AI 模型评分和排名数据。

我们不会收集以下信息：

  • 个人身份信息（姓名、电话、邮箱、身份证号等）
  • 设备识别信息（IMEI、IDFA、设备序列号等）
  • 位置信息（GPS、IP 地址定位等）
  • 通讯录、短信、通话记录等敏感信息
  • 照片、视频、文件等媒体内容
  • 浏览历史、搜索记录等行为数据
  • 用户账号、密码或支付信息

🌐 数据来源说明

本应用展示的数据均来自以下公开数据源，不涉及任何用户个人数据：

  • LMSYS Chatbot Arena — 大模型综合能力 ELO 评分和排名
  • Hugging Face API — 开源模型的热门度、下载量和趋势数据

以上数据均为公开可查的第三方平台数据，本应用仅负责整合展示。数据的准确性以原始平台为准。

📡 网络访问

本应用需要网络访问权限，用途仅限于：

  • 从 GitHub Pages 获取每日更新的排行榜数据（JSON 格式）
  • 从 Hugging Face API 获取热门模型和趋势数据

网络请求中不包含任何用户身份识别信息，仅为获取公开的 AI 模型数据。

🔗 第三方服务

本应用不集成以下任何第三方服务：

  • 第三方数据分析/统计 SDK（如 Google Analytics、友盟等）
  • 第三方广告 SDK
  • 第三方社交登录 SDK
  • 第三方推送通知 SDK
  • 第三方崩溃报告 SDK

应用内可能包含指向第三方网站的链接（如 Hugging Face 模型详情页），但我们不对这些第三方网站的隐私保护措施负责。建议您在访问第三方网站时阅读其隐私政策。

💾 数据存储与安全

本应用可能在您的设备本地缓存排行榜数据以提升加载速度，这些缓存数据：

  • 仅存储在您的设备本地
  • 不包含任何个人信息
  • 您可以随时通过删除应用来清除所有缓存
  • 不会上传到任何服务器

👶 儿童隐私保护

本应用面向所有年龄段用户。由于我们不收集任何个人信息，因此也不存在收集未成年人信息的情形。 本应用展示的内容均为 AI 技术领域的公开数据，不含任何不适合未成年人的内容。

📝 隐私政策的变更

我们可能会不时更新本隐私政策。当我们做出重大变更时，我们将通过应用内通知或在本页面上发布新版本来通知您。 建议您定期查看此页面以了解最新的隐私政策。

本隐私政策自发布之日起生效。
